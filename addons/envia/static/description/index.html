Envia Shipping for Odoo

Quote, label, and track Envia.com shipments from Sales and Inventory

Key Features

  • Get shipping rates from Envia.com directly inside Odoo.
  • Launch the quote wizard from sale orders and delivery orders.
  • Compare carrier services and select the best rate.
  • Create shipping labels and store tracking information.
  • Configure sandbox and production Envia credentials per company.

External Service Notice

This module connects to the Envia.com API to request quotes, create shipments, and retrieve tracking updates. You must configure valid Envia API credentials in Settings. Shipment data such as addresses, package details, and contact information is transmitted to Envia when you request rates or generate labels.

Configuration

  1. Install the module and open Settings > Envia Shipping.
  2. Enter your Envia API token and choose sandbox or production.
  3. Open a confirmed sale order or delivery order and click Get Envia Rates.
  4. Select a rate, confirm the quote, and generate the label when ready.
